# Dance World - E-Commerce Dance School Website

A beginner-friendly, blue-themed college project built with HTML, CSS and JavaScript.

## Included features
- Home and About pages
- Sign Up, Login and Forgot Password demo pages
- Classical courses: Bharatanatyam and Kathak
- Western courses: Hip Hop and Western Freestyle
- Course cards with sample monthly prices
- Shopping cart with quantity controls and demo checkout
- Contact Us and Enquiry forms
- Terms & Conditions, Privacy Policy and FAQ
- Responsive navigation and mobile layout

## Run in VS Code (Windows)
1. Extract `Dance-School-Website.zip`.
2. Open Visual Studio Code.
3. Choose **File > Open Folder** and select the extracted `Dance-School-Website` folder.
4. Open the Extensions panel (left side).
5. Search for **Live Server** and install it.
6. Open `index.html`.
7. Right-click inside the editor and select **Open with Live Server**.

You can also double-click `index.html` to open it in a browser, but Live Server is recommended.

## Important project-demo limitations
- This is a front-end demonstration. Sign-up data is stored in browser local storage and is NOT secure.
- Do not enter real passwords or sensitive personal information.
- Forgot Password only displays a demo message; it does not send email.
- Contact and enquiry forms display a local confirmation; they do not send data to an academy.
- Checkout is a demo only. No payment is processed and no enrolment is confirmed.
- A production website needs a backend, secure password hashing, database, email service, privacy/legal review and a trusted payment gateway.

## Files
- `index.html` - website structure
- `style.css` - blue responsive design
- `script.js` - navigation, courses, cart and demo forms
